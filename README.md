# DFD-PlantUML experiments

This repository is the testing and experimentation space for DFD-PlantUML. The official library, supported API, examples, and release history belong to [ArmanAvanesyan/DFD-PlantUML](https://github.com/ArmanAvanesyan/DFD-PlantUML).

Files here may change independently, have incompatible APIs, or fail to render. Do not use `test/main` as a production include or as a dependency of an official release. Pin an official source commit for reproducible diagrams.

Use this repository to explore alternate notations, Level 2, initialization APIs, and other proposals. Promote a coherent, verified implementation through a PR to the official repository with compatibility tests and rendered evidence. Experiments and historical files remain here; the two repositories are not automatically synchronized.
